# Essai

## תוכן האתר

המאגר מתחיל באוסף דפי תוכן בעברית לאתרים היסטוריים וארכאולוגיים בישראל. דפי התוכן כתובים ב־Markdown עם שדות נתונים בתחילת הקובץ, כדי שאפשר יהיה בהמשך לחבר אותם לממשק לפי אזור ולמפה אינטראקטיבית.

- תבנית ריקה: [content/templates/site-page.md](content/templates/site-page.md)
- דף הדגמה: [content/sites/demo-tel-hazor.md](content/sites/demo-tel-hazor.md)
- בדיקת עובדות נפרדת לדוגמה: [content/review/demo-tel-hazor-verification.md](content/review/demo-tel-hazor-verification.md)

## כלל תוכן חשוב

קובץ content/review/ הוא חומר עריכה פנימי, ואסור לכלול אותו בפלט הציבורי של האתר. כל עמוד חדש צריך לכלול מקורות לכל טענה מרכזית, פרטי ביקור עדכניים עם תאריך בדיקה, והרשאות מתאימות לכל תמונה או סרטון. דפים עם status: demo או demo: true הם המחשות בלבד ואינם תוכן מאומת לפרסום.
